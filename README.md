# קשרלי (Kesharli)

אפליקציית תקשורת משפחתית: ילדים משוחחים רק עם אנשים שההורים אישרו, וההורים מנהלים את מעגל התקשורת — בלי ספר טלפונים, בלי חיפוש משתמשים ובלי פניות מזרים. כל ההרשאות נאכפות בשרת.

A family messaging app where children can only talk to people their parents approved. Every permission is enforced on the server.

| | |
|---|---|
| `server/` | API — Node.js 22, TypeScript, Fastify, PostgreSQL, WebSocket |
| `app/` | אפליקציה — Expo (React Native) ל-iOS, Android ו-Web, עברית ו-RTL |
| `e2e/` | בדיקת עשן בדפדפן (Playwright) של הזרימות המרכזיות |
| `docs/` | [ארכיטקטורה ואבטחה](docs/ARCHITECTURE.md) · [פריסה](docs/DEPLOYMENT.md) · [מה נשאר לפני השקה](docs/ROADMAP.md) |

## מה עובד היום

שלב 1 (MVP) מהאפיון מומש במלואו, וכן חלק משלב 2:

- **כניסה**: הורים ואנשי קשר — קוד SMS חד-פעמי למספר הטלפון. ילדים — קוד חיבור חד-פעמי (15 דקות) שההורה מפיק. לילד אין סיסמה ואין מספר טלפון שאפשר לפתוח איתו חשבון עצמאי.
- **משפחה**: יצירה עם רישום הסכמה (תנאים, פרטיות, הסכמת הורה), ילדים, הורים נוספים עם הרשאות נפרדות (ניהול אנשי קשר / אישור בקשות / הגדרות), העברת בעלות ומחיקת משפחה באימות SMS נוסף.
- **אנשי קשר — הלב של המוצר**: הוספה ידנית בלבד, הרשאה נפרדת לכל ילד, הזמנה שקשורה למספר הטלפון שאליו נשלחה (קישור שהועבר לאדם אחר לא יעבוד), סטטוסים: ממתין לאימות / ממתין לאישור הורה / מאושר / נדחה / חסום / הוסר. בקשות של ילד להוספת איש קשר. חסימה שנכנסת לתוקף מיד בכל המכשירים המחוברים.
- **צ'אט בזמן אמת**: הודעות טקסט ואימוג'ים, נשלח/נמסר/נקרא, מונה הודעות שלא נקראו, חיפוש, מחיקת הודעה, תור הודעות כשאין חיבור עם שליחה חוזרת בלי כפילויות, סנכרון אחרי התחברות מחדש, קבוצות משפחתיות.
- **לוח בקרה להורה**: ילדים, אנשי קשר מאושרים, מכשירים, בקשות ממתינות, דיווחים, "עם מי ומתי" (בלי תוכן ההודעות), התראות אבטחה, יומן פעולות.
- **בטיחות**: דיווח ובקשת עזרה מהילד להורה, שעות שקטות, אישורי קריאה, ניתוק מכשירים, מדיניות שמירת הודעות, ייצוא מידע ומחיקת חשבון.

**מה עדיין לא קיים**: תמונות, הודעות קוליות ושיחות קול/וידאו (ההגדרות נשמרות כבר, אבל השליחה עצמה לא ממומשת); הצפנה מקצה לקצה; שליחת SMS ו-Push אמיתיים דורשת חשבונות אצל ספקים. ראו [ROADMAP](docs/ROADMAP.md).

## הרצה מקומית

דרוש: Node.js 22 ו-PostgreSQL 16.

```bash
# 1. מסד נתונים
createdb kesharli

# 2. שרת
cd server
cp .env.example .env          # ומלאו APP_SECRET: openssl rand -base64 48
# לפיתוח בלי ספק SMS הוסיפו ל-.env:  DEV_EXPOSE_OTP=true
npm install
npm run seed                  # יוצר מסד נתונים ונתוני הדגמה (משפחת כהן)
npm run dev                   # http://localhost:4000

# 3. אפליקציה (בטרמינל אחר)
cd app
npm install
npx expo start                # w = דפדפן, i = iOS, a = Android
```

לטלפון פיזי או לאמולטור Android יש להגדיר את כתובת השרת ב-`app/.env.local`
(`EXPO_PUBLIC_API_URL=http://<כתובת-המחשב-ברשת>:4000`; באמולטור Android: `http://10.0.2.2:4000`).

### חשבונות הדגמה

`npm run seed` יוצר משפחת הדגמה מסומנת (`is_demo`), במספרים בטווח 050-000-00xx בלבד:

| מי | איך נכנסים |
|---|---|
| מיכל — הורה ראשי | מספר `050-000-0001` |
| יואב — הורה נוסף (בלי הרשאת הגדרות) | מספר `050-000-0002` |
| סבתא רחל — איש קשר מאושר לשני הילדים | מספר `050-000-0010` |
| נועה, איתי — ילדים | "אני ילד/ה" + קוד החיבור שהסקריפט מדפיס |

כשאין ספק SMS, הקוד נכתב ביומן השרת; עם `DEV_EXPOSE_OTP=true` הוא מוצג גם באפליקציה עם תווית "מצב פיתוח". שתי האפשרויות נחסמות אוטומטית כש-`NODE_ENV=production`.
`npm run seed -- --reset` מאפס את נתוני ההדגמה ומדפיס קודי חיבור חדשים.

## בדיקות

```bash
cd server && npm test        # 55 בדיקות מול PostgreSQL אמיתי (TEST_DATABASE_URL, ברירת מחדל kesharli_test)
cd app && npm run typecheck
cd e2e && npm install && node smoke.mjs <קוד-החיבור-של-נועה>   # דורש שרת + אפליקציית web רצים
```

`server/test/security.test.ts` מכסה את 12 תרחישי החובה מהאפיון (ילד לא שולח לאיש קשר לא מאושר, זר לא מגלה ילדים, שינוי מזהה שיחה לא נותן גישה, אישור לילד אחד לא חל על אח, חסימה, הרשאות הורה נוסף, בידוד בין משפחות, אין קבצים ציבוריים, התחזות, ביטול גישה במכשירים מחוברים, סנכרון הודעות, ושחזור חשבון שלא עוקף בקרת הורים).
`e2e/smoke.mjs` מריץ בדפדפן אמיתי: כניסת הורה, הוספת איש קשר, חיבור מכשיר ילד, שיחה חיה בין ילד לסבתא, קבלת הזמנה, ניסיון שימוש בהזמנה של אחר, חסימה, ומצב כהה.
